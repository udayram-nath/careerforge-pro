# CareerForge Pro

ATS-Proof Resume Generator & Job Matcher

## Features

- 📝 **Resume Builder** - Create professional resumes with easy-to-use form
- 🎨 **8 Professional Templates** - Modern Blue, Executive, Minimalist, Creative, Classic, Tech, Modern Minimal, ATS-Optimized
- 🔤 **12 Premium Fonts** - Roboto, Open Sans, Lato, Montserrat, Poppins, and more
- 📋 **JD Analysis** - Paste job descriptions, extract keywords & get ATS score
- ✉️ **Cover Letter Generator** - Generate cover letters in 3 tones
- 🤖 **ATS Checker** - Upload & analyze existing resumes
- 📄 **Export Options** - PDF, DOCX, and JSON export
- 💾 **Save Resumes** - Save multiple resume versions
- 👤 **User Accounts** - Login/signup to save your resumes

## Tech Stack

- React.js + Vite
- CSS Modules
- html2pdf.js
- docx.js

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open http://localhost:5173/

## Build for Production

```bash
npm run build
```
